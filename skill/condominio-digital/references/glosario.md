# Palabras técnicas, en simple

Úsalas así con la persona (o evita la palabra técnica si puedes).

| Palabra | Dilo así |
|---|---|
| Apps Script | «el programita que vive dentro de tu hoja» (Extensiones → Apps Script) |
| Implementar / implementación | «publicar el programita para que el sitio pueda leer la hoja» |
| URL `/exec` | «la dirección de tu hoja para el sitio; termina en /exec» |
| `/dev` | «una dirección de prueba que solo te funciona a ti; no sirve para el sitio» |
| Nueva versión | «actualizar el programita sin que cambie su dirección» |
| Permisos / autorización | «Google te pregunta si dejas que tu propia hoja mande correos y guarde el PDF en tu Drive» |
| «App no verificada» | «Google avisa porque el programita no lo publicó una empresa; es tuyo» |
| Disparador | «la alarma que corre algo solo, por ejemplo el día 10» |
| JSON / ficha | «el archivo con los datos de tu condominio que bajaste del configurador» |
| Caché | «el sitio guarda las cifras 5 minutos; por eso un cambio tarda un poquito» |
| Cloudflare Pages | «el lugar gratuito donde vive tu sitio» |
| Repositorio (GitHub) | «la carpeta en internet donde se guardan los archivos del sitio» |
| Agregado | «sumado: cuánto en total y cuántas unidades, sin decir cuáles» |
| SHA-256 / huella | «la clave se guarda revuelta; ni nosotros podemos leerla» |
